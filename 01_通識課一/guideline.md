# 🃏 21 點遊戲程式專案：撰寫開發指引

這份指引列出了課堂投影片上，所有**撰寫 21 點遊戲專案的任務環節**，幫助各位學員，能夠在撰寫過程中快速對照。

---
## 📑變數名稱規格表 (依程式執行順序編排)
| 變數名稱 | 涵義說明 |
| :--- | :--- |
| `start` | 決定遊戲開始和結束的**狀態變數**
| `i` | 迴圈計數器
| `card_list` | 牌堆清單
| `player_cards` | 玩家手牌清單 
| `dealer_cards` | 莊家手牌清單 
| `add_card` | 決定是否加牌的**狀態變數**
| `player_points` | 玩家總點數
| `dealer_points` | 莊家總點數
| `win` | 決定是否獲勝的**狀態變數**
---

## ⌨️ Task 1：主程式碼撰寫
> **任務內容**：  
根據遊戲規則，填入正確的主程式邏輯，完整主程式模板。

### 📋 主程式執行區塊如下 :
1.  **建立牌組**
2.  **輸出玩家、莊家明牌**
3.  **判斷「玩家點數」是否大於 21 點**
4.  **輸出 玩家/莊家 的牌面及總和**
5.  **判斷玩家是否加牌 / 判斷輸贏條件 / 判斷輸贏**

---

## 📄 Task 2：函式功能對應
> **任務內容**：  
1.在宣告後面的註解，打上可能需要的「關鍵語法」。  
2.若有餘力，可嘗試自行撰寫函式內部程式碼，以及剩下牽涉到函式功能的程式碼。

其中第一點撰寫範例如下 :
```python
def Have11(hand): #11轉換成1判斷函式:內包含in運算子語法、...
  ________________ 

def draw(deck,hand): #抽牌函式:...
  ________________

def separator(): #輸出分隔線函式:...
  ________________
```


### 🛠 函式規格表

| 函式名稱 |參數說明 | 功能說明 |
| :--- | :--- | :--- |
| `Have11(hand)` | `hand` : 手牌清單|**11 轉換為 1**：當總和大於21(爆牌)時，將 A (11)  全部視為 1。
| `draw(deck, hand)` |`deck` : 牌堆清單 <br> `hand` : 手牌清單 | **抽牌邏輯**：從牌組中取出一張牌，並加入手牌。 
| `separator()` |無 | **視覺優化**：輸出裝飾性的分隔線。
